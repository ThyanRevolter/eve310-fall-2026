From counts to scores

Each score is one fraction of the counts above.

Precision TP / (TP + FP) – Of the flagged wells, how many are real detections? Nothing is flagged, so this is 0 / 0. The lab reports 1 (zero_division=1).
Recall TP / (TP + FN) – Of the real detections, how many did we catch?
Accuracy (TP + TN) / all – Right answers of both kinds. Misleading when one class is rare.

Try this

  1. On the ten testing wells, start at 0.50: three wells are flagged, two of them real, and three detections are missed. Precision 0.667, recall 0.4, the numbers from Lecture 16. Now drag to 0.30. Two more wells are flagged, both real detections. Both scores rise to 0.8.
  2. Drag the threshold up slowly and watch recall. It only ever steps down or stays flat: removing a flag either drops a false alarm (recall unchanged) or loses a real detection (recall down). Precision tends to rise, but it can dip when a real detection loses its flag before a false alarm does.
  3. Switch to all 643 wells and drag past 0.82. Nothing is flagged. Recall is 0, and precision shows 1 only because of the zero_division=1 convention.
  4. A missed detection leaves people drinking contaminated water. A false alarm costs one more lab test. Which way should a county move the threshold, and which score does it give up to get there?
