Four kinds of answer

The model gives a probability. A threshold turns it into yes or no. Every prediction lands in one of four cells: rows are the truth, columns are the prediction.

Predicted 0
Predicted 1
True 0
TNcorrectly not flagged
FPfalse alarm
True 1
FNmissed detection
TPcorrectly flagged
Accuracy(TP + TN) / allRight overall. Fooled by a rare class.
PrecisionTP / (TP + FP)Of what we flagged, how much was real.
Recall (TPR)TP / (TP + FN)Of the real positives, how many we caught.
F12 P R / (P + R)High only when both are high.
FPRFP / (FP + TN)Real negatives wrongly flagged. The ROC x-axis.

Which cell hurts most? A missed contaminated well is an FN. A pipe dug up for nothing is an FP.
