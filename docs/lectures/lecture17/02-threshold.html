What to notice

  • Lower the threshold: more wells flagged, recall up, precision usually down. You move up and right on the ROC curve.
  • Between 0.20 and 0.40 both are 0.8, the point nearest the top-left corner.
  • The ROC curve depends only on how the model ranks the wells; the threshold picks a point on it. AUC 0.80. A coin flip scores 0.50.
