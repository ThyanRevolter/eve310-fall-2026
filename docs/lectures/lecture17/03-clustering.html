Same table, label column deleted. Find groups whose members are similar to each other and different from the other groups.

Next lectures answer three questions:

Where it shows up: communities in social networks, genes that act together, faces in a photo app, groundwater sources grouped by contaminant profile to decide which wells to monitor most.
