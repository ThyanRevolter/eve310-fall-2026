## How students run it

Labs are Colab-only. There is nothing to install.

1. Open the notebook from the [course website](https://thyanrevolter.github.io/eve310-fall-2026/labs/) — the **Open in Colab** button
2. Click **Copy to Drive** before typing anything
3. Run the setup cell at the top, then work down the notebook
4. **File > Download > Download .ipynb** and upload the activity to Gradescope

Full walkthrough: [docs/setup.md](../../docs/setup.md).

## Notes for staff (delete before publishing)

Copy `_template/notebooks/template.ipynb`, then:

1. Replace `{{LAB_ID}}`, `{{LAB_NUMBER}}`, `{{LAB_TITLE}}`, and `{{MODULE}}` throughout
2. List this lab's data files in `DATA_FILES` in the setup cell
3. Put those files in `data/` and **push to `main` before the lab session** — the setup cell
   downloads them from `raw.githubusercontent.com`, so an unpushed file does not exist for
   students
4. Add the lab to `docs/labs/` and to the table in `docs/labs/index.md`

The setup cell needs the repository to stay public. If it is ever made private, every lab's
data download breaks and the files have to be distributed through Canvas instead.
